# ClassPing

Free static attendance tracker for GitHub Pages.

## Publish
1. In repository Settings, open **Pages**.
2. Under Build and deployment, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for deployment. Site URL: https://aaaryannn0905.github.io/classping/

## Notes
- Add classes and mark attendance in the app.
- Use Export backup to save data; Import backup asks for confirmation before replacing local data.
- Data is stored in browser localStorage and does not sync across devices.
- Notifications require permission and work only while the page is running; GitHub Pages alone cannot guarantee alarms when the browser is closed or phone is locked.
